# Compact workspace implementation contract

Approved scope: COMPACT-WORKSPACE.md, all four implementation steps. Draft/review, scoped flows, native Worker and notification safety remain invariants. Human changes publish only at final reviewed Submit; canonical agent graph tools still publish immediately.

This is the implemented internal contract, not onboarding. Start with the [user guide](USER-GUIDE.md) for everyday tasks. Later search, Center selection and palette controls extend the shell without changing its draft/publication boundary.

## Component interfaces

The shell (`index.html`, `style.css`, `workspace.js`) owns layout, menus and accessibility. The editor (`app.js`) owns gestures and draft commands. The backend owns validated atomic/coalesced operations. Existing IDs identify real controls in their contextual homes; do not add hidden duplicates to preserve outdated tests.

## Backend

Extend draft_change input with editGroup?:string (max128). Add operation {type:'batch',operations:LeafOperation[]} (1..300, no nesting). All leaf operations use existing contracts and commit atomically as one checkpoint/version increment, or no mutation on error. Node/edge membership, scoped positions, human retirement and captured drawings remain protected. A batch is not exempt from frame protection. The full batch produces one durable Undo action and one eventual reviewed delta, with no watcher event.

Consecutive saves of one existing node/edge or one instruction may share an editGroup. First save creates a checkpoint; following saves with the same group and target replace ONLY that group's current checkpoint work payload, incrementing version for CAS. Preserve the preceding checkpoint. Different target/group, batch/gesture, undo/redo, rebase, submit or discard end coalescing. Group metadata is additive in the draft JSON; old records default to no group. After undo, a new edit branches normally and removes redo. Never coalesce across tabs' version mismatch, bypass replay or erase previously committed history. Export a reusable draftChangeSchema for AgentAPI input rather than accepting unvalidated extra fields.

## Shell / editor bridge

public/workspace.js exports initWorkspace(callbacks), returns {setTool(tool), getTool(), showPanel(tab='properties'), refresh(state)}. tools: select|hand|node|connect|draw|erase. callbacks: onTool(tool), onCommand(command), onPanel(tab). Shell has no graph/draft mutations and does not install canvas/undo shortcuts (editor owns those). setTool updates selected visuals/options without calling onTool recursively; user tool clicks invoke onTool. refresh receives {selectionCount,hasSelection,toolHint,saveState,saveError,connectionState,zoomPercent,conflict} as available; must tolerate missing optional fields. Use no circular import or synthetic input/click events to fake actions. UI-only Inspector/menu state belongs to shell.

Preserve core IDs: canvas/nodes/edges/ink, title, sessions/session-id/open-session (File popover), revision/counts/subtitle/draft-version/turn-status/turn-detail/flow-context (details popover, not hidden duplicate shims), connection/watcher-status (Connection popover), flow-selector/add-flow/edit-flow (scope management), layout-direction/auto-layout/auto-layout-connected/auto-layout-tags/cancel-layout/undo-layout (Arrange; computing/saving status in command row, no Apply control), focus-relations/show-retired (View), fit/zoom-in/zoom-out (status), pen (Draw tool), add-node/connect-nodes (toolbox), clear-ink (Draw menu), inspector/editor/hint/node-* and flow role fields, edge-* forms/picker, feedback-note/list/target (Agent panel), send-feedback (single Review button in document row), history-toggle/history (History panel), existing modal IDs. Editor calls showPanel properties on selecting/creating node/edge and Agent on explicit note access, not every rerender.

## Editor

Explicit exclusive tool state; V/H/N/C/P/E keys outside editable fields/dialogs/IME. Temporary Space Hand with middle-pan preserved. Add node click places draft form at world point, focuses Label, creates only on valid explicit save, then Select. Connect click source/target or drag source handle to target; visible preview/target highlight, self/parallel links valid, Escape cancels with no stored edge. Keep Inspector connection authoring as accessible fallback. Erase removes only hit whole strokes with one instruction checkpoint per gesture. Escape cancels uncommitted placement/connector/stroke and never discards durable work.

Selection Set plus primary selected node, Shift additive and blank marquee; ordinary click clears focus, Ctrl retains existing connection-focus semantics. Drag selected nodes together, pointer-up one batch move in selected scope. Arrow nudge1 (Shift10), align left/top and distribute horizontal/vertical (3+ nodes) atomic scoped batches. Suppress geometry changes with drawings/active forms as existing contract. Multiple selected nodes outlined; Inspector selection summary and commands; one node retains existing editor/role controls. Context menu selection actions can share command dispatch, not duplicate mutation code.

Copy captures selected nodes/internal edges and selected-view geometry in a private in-memory clipboard; Paste/Duplicate generate all-new IDs, offset positions, copy content/sources, and only add to the current scope. Do not copy boundary roles or unrelated memberships; never steal original semantic identity. Batch creates nodes before internal edges. Clipboard commands never hijack native text input shortcuts.

Existing-object valid property autosave after idle (~600ms) and blur/Enter, grouped by one editing session/object; focus exit or selection/tool/session/review/undo closes the group. New objects still explicit create. Avoid overwriting newer form text when earlier saves return; only clear dirty if the exact saved form still matches. Invalid input remains visible with field validity and persistent save error, no false Saved state. Flush valid input before switching; otherwise keep original scope/selection and explain Save/Discard. Ctrl/Cmd+S flushes draft only. Ctrl/Cmd+Z outside inputs awaits/flushes current edits then draft Undo; native input undo retained. Track composition; no autosave/shortcuts mid-IME.

Editor refreshes shell state on meaningful UI/draft/zoom changes, not announcements every pointer move. Preserve truthful delivery states and explicit conflict UI. Native Worker completion saves directly to draft after version checks; cancellation before saving writes nothing. Draw capture/rebase and one final review packet remain intact.
